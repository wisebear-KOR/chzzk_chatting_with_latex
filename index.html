치지직 LaTeX 채팅 위젯

치지직 기본 채팅 위젯과 같은 모양인데, 채팅에 LaTeX 문법이 있으면 수식으로 그려 줍니다.

데모 미리보기 · 위젯 URL 은 치지직 스튜디오의 채팅 위젯 설정에서 복사할 수 있습니다.

수식 쓰는 법 (시청자)

$ ... $문장 안 수식. 예: 오일러 공식 $e^{i\pi}+1=0$
$$ ... $$가운데 정렬된 큰 수식. \( \), \[ \] 도 됩니다.
구분자 없이\frac, \sqrt 같은 LaTeX 명령이 있으면 자동 감지합니다. 예: 답은 \frac{1}{2} 입니다
화학식\ce{2H2 + O2 -> 2H2O}

수식만 보낸 채팅은 자동으로 큰 수식으로 표시됩니다. 잘못된 문법은 그냥 원래 글자로 보입니다.

URL 옵션

hash치지직 채팅 위젯 URL 끝의 32자리 값 (URL 전체를 넣어도 됩니다)
detectauto(기본) · delimiter($ 등 구분자로 감싼 것만) · off
demo=1가짜 채팅으로 모양 미리보기
chatChannelId자동 조회가 안 될 때 직접 지정 (방송을 켤 때마다 바뀌는 값)
